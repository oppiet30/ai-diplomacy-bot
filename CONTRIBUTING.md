# Contributing

Create a branch and open a pull request. Keep real API keys, private configuration,
logs and player messages out of Git. Test with fixtures or isolated local servers,
not production games. Preserve third-party licenses and copyright notices.

Run both unittest suites documented in README.md. AI-assisted commits should include
an attribution trailer such as `Assisted-by: Codex:gpt-6.1-sol` and describe testing
limitations. A passing test suite is not a benchmark of strategic playing strength.
